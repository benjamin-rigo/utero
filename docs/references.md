# Referenciák: mit nézzünk meg, mielőtt modellezünk

A tulajdonos ízlése alapján összegyűjtött eszközök. Mindegyiknél azt jelöltem, melyik roadmap-ponthoz ad ötletet.

## Noise Engineering (ezeket kérted)
- **Basimilus Iteritas Alter**: additív/FM ütőhangszer-szintézis, agresszív kick és perc → kick, perc, tom machine.
- **Manis Iteritas**: durva, torzított perkusszív hangok → perc, ornament.
- **Loquelic Iteritas**: VOSIM / formáns oszcillátor → lead, ornament.
- **Desmodus Versio**: reverb, sötét és modulált → reverb.
- **Imitor Versio**: többfejes delay → delay.
- **Ruina**: többlépcsős torzító (plugin) → drive.
- **Sinc Iter**: hullámtábla és szűrő karakter → bass, lead.

## Elektron (ezeket kérted)
- **Analog Rytm MKII**: analóg drum machine-ek (BD Hard / Classic, SD, HH, CY, CB), compressor és distortion → kick, snare, hats, perc, master comp.
- **Syntakt**: digitális és analóg machine-ek ugyanazzal a 8 potis felülettel → a machine-jeink felépítése.
- **Digitone II**: FM Tone, FM Drum, Wavetone, Swarmer → lead, pad, FM perc.
- **Model:Cycles**: Kick / Snare / Metal / Perc / Tone / Chord, kevés paraméterrel → egyszerű machine-ek.
- **Digitakt II**: sampler és a beépített effektek → sample machine.
- **Octatrack**: lo-fi, comb filter, effekt routing → insert FX ötletek.

## Make Noise (ezeket kérted)
- **Strega** (Alessandro Cortinival): delay és drone-generátor, a Time és az Activation egymásba visszacsatolva → feedback, delay, ornament.
- **Mimeophon**: sztereó, több zónás delay, „halo” → delay.
- **Morphagene**: szalagos / granuláris → sample machine, granuláris FX.
- **Erbe-Verb**: modulált, gesztusokra épülő reverb → reverb.
- **QPAS**: négy csúcsú, animált szűrő → filter.
- **0-Coast / DPO / Optomix**: west coast szintézis (komplex oszcillátor, wavefolder, LPG) → lead, ornament, perc.
- **Maths / Wogglebug**: függvénygenerátor, véletlen → modulátorok.

## Soundtoys (ezeket kérted)
- **Decapitator**: analóg szaturáció, öt karakterrel → drive.
- **EchoBoy**: delay-karakterek (szalag, BBD, digitális) → delay.
- **Crystallizer**: granuláris, visszafelé lejátszott echo → feedback / ornament FX.
- **FilterFreak, PhaseMistress, Tremolator, PanMan**: ritmikus, szinkronizált modulációs effektek → insert FX.
- **Devil-Loc**: durva kompresszió és torzítás → drive, master.
- **SuperPlate / Little Plate**: plate reverb → reverb.
- **MicroShift**: szélesítés → chorus.

## Ugyanebben a stílusban, érdemes megnézni
- **Mutable Instruments** (Plaits, Rings, Elements, Clouds, Beads): nyílt forráskódú, tehát az algoritmusok elolvashatók → machine-ek, granuláris FX, rezonátor.
- **Valhalla** (VintageVerb, Supermassive): a reverb-algoritmusokról részletes blog → reverb.
- **Ableton** (Reverb, Echo, Roar, Drum Buss, Saturator): a reverbjét kedveled, a Roar feedback-routingja → reverb, feedback, drive.
- **Sonic Charge Microtonic**: kifejezetten techno drum szintézis → kick, perc, hats.
- **Erica Synths Perkons HD-01**: drum machine sokféle torzítással → perc, drive.
- **Chase Bliss** (MOOD, Habit) és **Strymon** (BigSky, Volante): looper és visszacsatolásos delay, reverb → feedback, reverb.
